## System Features
- Array Operations (Insert, Delete, Search, Display)
- Stack Operations (Push, Pop, Peek, Display)
- Queue Operations (Enqueue, Dequeue, Peek, Display)
- Linked List Operations (Insert, Delete, Search, Display)
- Searching Algorithms (Linear Search, Binary Search)
- Graph Operations (Add Vertex, Add Edge, BFS Traversal, DFS Traversal)
- Performance Comparison & Algorithm Complexity Analysis

## How to Run
1. Clone the repository.
2. Compile the Java files using `javac Main.java`.
3. Run the application using `java Main`.
